Projects

Closed-Loop Thermal Fan Controller

A fan controller that reads ambient temperature and holds it to a setpoint, built the way an HVAC system would be.

A DHT11 sensor feeds live temperature readings to the controller, which drives a fan through PWM to hold a target set by a potentiometer. An LCD shows the current reading and setpoint, and the loop logs over serial for tuning.

Cat vs. Dog Image Classifier

A convolutional neural network trained from scratch to tell cats from dogs, with no pretrained weights.

Built in PyTorch on a two-conv-layer architecture with data augmentation, currently reaching 84% test accuracy. The constraint is deliberate: get there without transfer learning, then push past 88%.

GO FSU Scrolling Display

A Verilog project that scrolls "GO FSU" across a DE1-SoC board's seven-segment displays. See the live recreation above.

Built from four modules (a clock divider, a finite state machine, a message ROM mapping frame number to character, and a display driver), written and simulated in Quartus Prime.
